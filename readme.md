# From Nand to Tetris — My OSSU Journey

[NandtoTetris](https://www.nand2tetris.org) and [WebEditor](https://nand2tetris.github.io/web-ide/asm)

This repository is my personal progress log for one of the best and most favorite courses in the OSSU roadmap: Nand to Tetris.

I chose this course because it is not just about learning theory — it is about building a real computer from the ground up. Starting from the most basic building block, the NAND gate, and gradually moving through logic design, arithmetic, memory, machine language, computer architecture, assembly, virtual machines, compilers, and operating systems, this course gives a unique, hands-on understanding of how computers really work.

It is a course that connects many layers of computing into one continuous story, and that is why it stands out to me. Every project feels like a puzzle piece that finally clicks into place, making the entire system meaningful.

## Course structure and progress

### Part I: Build a Modern Computer from First Principles

This part focuses on the hardware foundation of a computer:

- Boolean logic and gate design
- Boolean arithmetic and the ALU
- Memory and registers
- Machine language
- Computer architecture
- Assembler development

In this repository, I implemented and studied the fundamental HDL projects such as:

- Logic gates: AND, OR, NOT, XOR, MUX, DMUX, etc.
- Arithmetic chips: HalfAdder, FullAdder, Add16, Inc16, ALU
- Memory elements: Bit, Register, RAM, PC
- Hardware architecture: CPU, Memory, and Computer modules
- Assembly programs and assembler logic

### Part II: From Nand to Tetris, Part II

This second part ,which is way better and more interesting for me, continues the journey upward into software and abstraction layers:

- Virtual Machine (stack arithmetic and program control)
- High-Level Language concepts
- Compiler I: syntax analysis
- Compiler II: code generation
- Operating system concepts

This part shows how software is layered on top of the hardware and how compilers and virtual machines make programming more productive and structured.

## Why this course is special to me

This is my favorite course in the OSSU roadmap -with [CS50x](https://github.com/FADY88/My-CS50x-Progress) and [MIT-CS-intro-with-python](https://github.com/FADY88/MIT-CS-intro-with-python)- because it gives a complete picture of computing, from transistors and logic gates to software execution and operating system behavior. It is one of the rare courses that turns abstract ideas into a tangible, working system.

Rather than learning isolated topics, I get to see the full stack:

- digital logic
- architecture
- assembly
- VM
- compiler
- OS

That full-stack perspective made this course both challenging and deeply rewarding and I'm proud of all the effort I put into creating Assembler, VMTranslator, SyntaxAnalyzer and Compiler for the Jack language using Python.

This repo contains my work, experiments, and implementations while following the Nand to Tetris curriculum. It reflects both my technical progress and my growing appreciation for how computers are built from first principles.

It is a record of learning, problem-solving, and the excitement of seeing a machine come to life step by step.
